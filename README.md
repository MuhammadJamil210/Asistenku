# AsistenKu — Sistem Penjadwalan Asistensi Praktikum

## 1. Deskripsi Proyek
AsistenKu merupakan proyek sistem penjadwalan asistensi praktikum yang bertujuan membantu proses pengaturan jadwal asistensi agar lebih terstruktur dan mudah diakses.

## 2. Permasalahan
Penjadwalan asistensi praktikum dapat mengalami kendala, seperti bentroknya jadwal, kesulitan memperoleh informasi jadwal, serta koordinasi antara mahasiswa dan asisten praktikum.

## 3. Tujuan Sistem
- Mempermudah pengaturan jadwal asistensi praktikum.
- Membantu mahasiswa memperoleh informasi jadwal.
- Mengurangi kemungkinan bentroknya jadwal asistensi.
